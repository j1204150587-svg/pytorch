# PTA 按相邻 storage 区段展平

动态 eager 双向 embedding 的 Level1 第 4、5 步在优化器展平 1,052 个分片时，`NPUNativeFunctions::flatten_dense_tensors` 的 CPU 范围为 5.874、5.910 ms，各含 1,052 次 format_cast、1,052 次 view、一次 cat。旧 #41 要求所有分片在列表次序上共同组成一个正序区间。其八步记录证实同一 ND storage、连续 BF16 以及全列表的总偏移条件失败，但只保留首次不匹配，不能据此判定每个相邻分片的关系。

本次由 PTA 逐项验证 storage、格式、尺寸、偏移、安全容量与梯度条件。就地识别正序邻接区段和等宽反序区段，前者按一段描述，后者调用现有 flip 倒转行序。其余项按原次序提供给 cat，结果要求独立存储。原训练审计逐步输出正反序长度与实际 cat 输入数量。独立微门覆盖数据顺序、非零偏移、不同长度、重复及不相邻片段、别名写入、梯度回退。未出现长区段、逐位或别名对照失败则停止。命中后检查同一步 flatten 内实际流和设备任务，分别计入 flip 和 cat，总工作数及端到端独立核算。该 CPU scope 给出了可见局部预算。
