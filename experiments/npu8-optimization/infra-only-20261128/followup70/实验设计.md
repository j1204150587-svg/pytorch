# 原动态 eager 的后续 Infra 验证

每一对共用 01、双向 embedding 描述符补丁、`ACLNN_CACHE_LIMIT=65536` 和 Task Queue Mode 1。每个候选在同一个原生库内切换，训练入口、模型和 60 个实际形状按原 runner 校验。端到端用 10 步预热后的 50 步同步窗。Level0 用第 4–6 步的 ΣFree/ΣStage。训练审计及 CPU 采样单独运行。

|候选|实测瓶颈和触发频次|机制|证伪条件|
|---|---|---|---|
|PTA `ReleaseQueue::WriteToReleaseQueue/ReadFromReleaseQueue`|原配方两次 8 秒 host perf 分别采到 2,156 和 2,103 个用户态样本。`acl_thread` 在设备工作提交后还向单生产者、单消费者的释放环传递资源，`release_thread` 处理并返还槽位。两条线程都采到释放环函数。|`WriteToReleaseQueue` 对读指针做 acquire、对写指针做 release。读侧对称处理。交接槽位前后的四次全内存屏障改为针对共享指针的同步。回调及资源析构仍在原线程执行。|环绕后序号、载荷或槽位所有权异常，或训练中的发布数与消费数不同，则停止。性能按真实流和任务核对，记录释放完成到下一笔工作前的可见间隙及端到端双序变化。|
|PTA `NPUNativeFunctions::empty/empty_with_format`|双向 embedding 的 Level1 第 4、5 步中，`empty_tensor` 分别有 7,743、7,744 次。全部线程上该 CPU 区间的并集与设备空档相交 21.844、22.331 ms，包含完整分配和描述符构建。|固定 PyTorch 的 `TensorImpl::set_sizes_contiguous` 会执行一次连续 stride 计算与 contiguous 标志刷新。在确实调用过它时跳过工厂中的第二次相同计算；单维零长特例沿用显式计算。|尺寸、stride、存储格式、报错行为、原训练梯度或权重有差异则停止。时间归因比较同一步同线程的工厂延迟和空档交集，完整函数的时间仅是局部预算。|

主机采样从容器外关联原训练 rank 的 PID。两腿均开同一双向 embedding 配方。perf 按 199 Hz 对全部训练线程采 `cpu-clock:u`，采样所对应的训练窗口只用于定位，正式端到端表使用独立运行。[采样脚本](host-samples/sample.py)
