# PTA 兼容选项的查询键复用

两次 199 Hz 训练采样中，主线程和 autograd 最内层 PTA 栈处于 `CheckCompatibleImpl` 的样本合计 25/28 个。候选在 `torch_npu/csrc/framework/interface/EnvVariables.cpp` 第一次使用时构造兼容选项的字符串键，随后每次仍查询原注册表。相同动态库的 CPU 微门按 AB 为 65.592→46.454 ns/次，BA 为 A 65.215、B 43.992 ns/次。原训练八步两进程各调用 462,947 次，计数打开时函数内累计 103.911→63.768 ms。[原生补丁](compatible-key.patch) · [实际计数](counts.json)

原生库 SHA-256 为 `1c86ad3a3851f02b1599a832bb31d780402212104806f5bceaf2c2444aa4783e`。正序裸跑和 Free 同向改善，反序两者均回退，归入尝试无优化路径。该候选没有已完成的专门非有限梯度注入和 Level1 数据，单次设备提交延迟或次数未验证。

## 配对结果

原动态 eager、01 分块 overflow、1,024 侧表、单 rank、梯度累积 1、BF16 ZeRO-2 及 TQ1。A/B 使用相同的 60 个合成 shape，B=1–4、L=12–32。裸跑预热 10 步后首尾同步，测量 50 步，共 136 样本、2,994 token。Level0 第 4–6 步分别为 [1,19]、[2,14]、[2,22]。Free 占比按三步总 Free 除以三步总 Stage，提升比例均按 (A−B)/A。
