# 按真实参数形状合并 ZeRO 梯度 norm

在直接发布梯度的动态 eager 训练中，第 4–6 步的 `flat_stats.row_norm_square` 共发起 123 次 `linalg_vector_norm`。先对整段梯度调用 `.double()`，再合并相邻同形状参数，剩余 25 组。目标 NPU wheel 接受 FP64 请求，实际产出 FP32 张量。4,380,544 个元素占 17,522,176 字节。CPU 对照上相同请求产出 FP64。

候选保留 1,024 张侧表的连续视图，用一次 `index_select` 聚集 116,544 个分散的普通参数元素，分 8 组执行 `vector_norm`。置换还原 1,052 个范数原有次序，再执行原有平方、求和及 FP32 转换。预建索引占 940,768 字节。该路径作用于 eager 优化器，每个可更新步调用一次。[实现](norm_by_shape.py)

逻辑 NPU 8 对标准、稀疏、大值、裁剪阈值附近、小值、全零、Inf 和 NaN 输入逐一比较，八组最终标量位值一致。每个同步窗口轮换四个真实大小的缓冲，包含整段转换、聚集和重排。四窗对照为 1683.90→322.24、1637.17→324.17、1624.36→320.97、1633.53→320.52 µs。A 保留逐片冗余转换，B 同时消除这些转换并按形状合并。训练配方单独切换去除冗余转换、25→8 分组，以各自整步配对测量增量。[NPU 原始结果](../diagnostics28/norm-shape-v2-1795828294221388218/micro.json) · [复测入口](micro.py) · [CPU 数值门](cpu.json)
