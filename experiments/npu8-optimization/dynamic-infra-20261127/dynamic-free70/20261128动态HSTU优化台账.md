# 动态 shape HSTU 训练的 NPU 8 优化台账

原始 01 与采用分组侧表、连续梯度叶、flat 统计、直接发布和 eager fold 的组合做双序对照，无 profiler 步时由 635.654→22.186、599.226→21.529 ms。组合的 Level0 Free 为 22.907、23.377 ms/步，占比仍为 86.55%、87.03%。各项增量具有不同的共同前置，组合收益取自直接实测。

在只开 01 的原始基线上，IPG 连续梯度复制将同流 1,052 个 SDMA 工作改为 1 个 TensorMove，正反序步时分别缩短 11.48%、6.11%，绝对 Free 分别减少 216.542、111.868 ms/步。以原始设备工作端点对齐，两个代表 shape 的局部空档分别减少 34.362、33.559 ms。已有 flat 梯度布局校验移入 C++ 后，在它自己的前置配置上双序步时缩短 14.78%、10.22%，Free 均下降。

## 负载、正确性与读数

所有训练前反向走 eager，固定单 rank、BF16 ZeRO-2、1,024 张侧表、累积步数 1、seed 1234、Task Queue Mode 1。逻辑卡 8 对应板 4、芯片 0，容器内为 npu:0。使用宿主共享锁和设备进程前后检查。各腿按相同步号直接生成实际尺寸，60 组互异的合成 [B,L]，B=1–4、L=12–32。此处没有真实业务 shape 频率，正式序列中每个完整 [B,L] 只出现一次。首见/再见另取同形状的诊断窗口。独立 01 stock 既有基线约 600.060 ms/步；下表一律使用同轮 A 作为分母。[60 个实际形状](working/evidence/grouped-side-v1-no-profiler-ab/workspace/configs/dynamic_shapes_npu8.json) · [01 基线与此前 D01–D05](../动态NPU8优化台账.md) · [输入、设备操作与测量原理](动态Free复测台账.md)

每项八列首行按 A/B 执行，次行按 B/A 执行，列方向都为 A→B。无 profiler 预热 10 步、首尾同步测 50 步，按同一窗口的 136 个样本、2,994 个 token 计算吞吐。独立 Level0 第 4–6 步为 [1,19]、[2,14]、[2,22]；Free 和 Stage 各自先求和再相除。两项提升比例分别为 1−步时 B/A、1−Free 占比 B/A。每项下方的逐步表含 ms/步、样本/s、token/s、Free/Stage/Computing 和配对波动。语义门按实际 shape 比较 loss、全部 1,052 份梯度、权重、优化器状态，并在步骤 2、4、6 注入非有限值核对跳步。候选具体差值和适用条件保留在各自对照文件。

- 在确定到同一流和设备任务的范围内，IPG 复制以后依然有约 10–11 ms 到下个已匹配工作的空档。已测到准备 1,052 个视图和梯度发布的部分时间，其余 Host 行为、依赖与设备排队尚未完全归因。[精细分段](ipg_range_copy/paired/RESULTS.md)
- **动态下发的时钟校准。** 在原生 RMS v2 的 B 配置追加末步校准，1,912 个 ACL 调用与真实任务的先后关系将设备到 Host 的共同时钟偏移约束在 16.020–24.550 μs。第 4、5 步已有队列等待与已关联全流空档的交集最多分别为 0.972、0.764 ms，workspace API 的交集分别为 2.429–2.668、2.177–2.460 ms。各阶段上下界可出现在不同偏移，单项训练收益另按实测。[完整时间分解、命令及逐笔收据](diagnostics28/clock-analysis/RESULTS.md)
- **Addmm 的只读描述符。** 原有 512 字节规范化保留实际地址余数，对 60 个形状的 480 次投影仍有 416 种几何。以 128 字节对齐地址建立同一数据指针的局部 storage 后，480 个 BF16 投影结果逐位相同。新进程正、反序的八投影窗口分别由 493.843→256.688、476.083→272.847 μs；共用进程依次执行的后两组仅改善 2.94%、回退 0.67%。两种形状的 workspace 查询各由 8 次降至 3 次，设备均为 8 个 Cast 和 8 个 Matmul。独立进程的物理流为 11、78，原生同流和整步收益另行验证。[几何与逐笔依据](addmm_alignment/README.md) · [两个进程模式、原始 trace 及复算](addmm_alignment/RESULTS-128.md)
- **反向 Mm 的只读权重几何。** 两步的 Mm workspace 与后继全流空档相交 0.604–0.620、0.552–0.576 ms。逐条重建 960 笔真实反向 Mm 几何，涉及只读权重的 480 笔在 128 字节地址规范化后从 416 种几何变为 104 种。目标镜像和独立 CPU 复算的全部记录逐字节一致；实际 NPU executor 命中仍须单做验证。[全部几何与验证条件](addmm_alignment/MM-GEOMETRY.md)
- 将 linear 反向的两次 MM 合并到 GroupedMatmulV5，四种实际形状的两类投影均逐位通过。但需要转置，设备工作仍为两笔，32 个配对窗口全部慢 23.329–29.597 μs/对。此前的整段因果 attention、RMS Triton、分行 flat stats 等数值或性能负例，已按对应算子门和训练门收录。[GMM 八组和原始 trace](linear_gmm/RESULTS.md) · [其余尝试与收据](动态Free复测台账.md)
