# 连续 IPG copy 两侧的梯度视图准备与发布

Level1 4、5 步的 A/B 都在流 44 仅提交一次 TensorMove。流 44、45、47 的全部物理任务顺序逐项相同，整步设备工作量分别为 16,169、16,170 笔。匹配前一笔流 45 的 MEMCPY_ASYNC 和下一笔流 47 的 ZerosLike 后，跨流空档分别为 29.568→17.709、29.915→17.733 ms。主要差别出现在 copy 前，18.627→7.593、18.787→7.642 ms，主线程可见的 `aten::narrow` 从每步 1,053 次降至 1、2 次。复制后仍可见 1,052 次兼容性检查。TensorMove 自身分别为 12.30→11.60、12.72→11.42 µs。该结果支持减少 Host 视图构造开销；整步 Level0 Free 的实测方向为回退。[原始跨流端点和分解](native-l1-ab/physical.json) · [直接复算](../paired_physical.py)
