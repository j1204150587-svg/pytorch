# Attention score 分块查表融合的实机语义门

两笔原生 matmul 保持相同。候选在二者之间用一个前向核执行缩放、BF16 SiLU 查表、因果掩码和除以序列长度，并用一个反向核执行对应梯度。普通 Triton 与 C++ 计划都按每块 128 项取数。已核验前后向二进制、启动参数顺序和 driver，两个真实 launcher 均未申请隐藏的 workspace 或同步锁。[前反向内核](kernels.py) · [地址和资源检查](operator_impl.py)
