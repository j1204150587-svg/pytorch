# 尝试无优化路径：linear 反向双乘并入 GroupedMatmulV5

目标 NPU 8 的四个真实 shape、两种投影共八组均成功运行。每组的 dInput、dWeight 逐个 BF16 位值与真实 linear autograd 相同。A 分别调用两个 MM，B 将 `dy.T.contiguous()` 与 GMM 一并计时。从五轮预热后的独立同步窗口计算，每组 A/B 与 B/A 各两轮，每腿每窗计算 32 对梯度。32 个配对窗口全部回退，每对梯度多用 23.329–29.597 µs。[八组配对、工作量与精度明细](npu-recomputed.json) · [逐腿原始 JSON](npu/summary.json)

| 实际 [B,L] | 投影 | 两次 MM 中位 µs | 转置与 GMM 中位 µs |
|---|---|---:|---:|
| [1,19] | 64→256 | 35.003 | 62.580 |
| [1,19] | 192→64 | 29.581 | 56.856 |
| [2,14] | 64→256 | 28.265 | 52.792 |
| [2,14] | 192→64 | 27.626 | 52.921 |
| [2,16] | 64→256 | 29.082 | 55.234 |
| [2,16] | 192→64 | 30.247 | 54.643 |
| [2,22] | 64→256 | 27.569 | 52.746 |
| [2,22] | 192→64 | 32.168 | 61.390 |

M=19 和 M=32 的两个投影分别独立采集 Level1，共八个 trace。每条 A 的物理流 47 上出现两次 MatMulV2。B 在相同流上先发一次 `aclnnInplaceCopy_TransposeAiCore_Transpose`，再发一次 `aclnnGroupedMatmulV5_GroupedMatmul_GroupedMatmul`。设备工作数均为 2。M=19/32 各自的 64→256 投影复制 9,728/16,384 字节，192→64 投影复制 2,432/4,096 字节。[原始小型 trace 包](npu/traces.tgz)

在这四个 M（19、28、32、44）上均能运行；实验没有观察到对齐导致的回退。该实现未进入训练改造和 50 步端到端验证。候选只覆盖四层块中每步八对乘法，stock 两步与这 16 个 MM 对应的前导全设备空档总和分别为 1.714、1.610 ms。[原训练调用链逐笔证据](stock-pairs.json)
