## 无 profiler 的 50 步同步窗口

每腿预热 10 步，同步后依次执行第 10–59 步，以窗口结束时同步后的总秒数计算吞吐。下表 A/B、B/A 均按 A → B 展示，A/A 按第一次 A → 第二次 A 展示。

| 轮次 | 执行顺序 | ms/步 | 样本/s | token/s | 相对缩短 | 同形状 Host 单步差 p10 / p50 / p90（ms） |
|---|---|---:|---:|---:|---:|---:|
| r1 | A/B | 635.654 → 22.186 | 4.2791 → 122.6002 | 94.202 → 2699.008 | +96.51% | 535.12 / 633.92 / 648.86 |
| r1 | B/A | 599.226 → 21.529 | 4.5392 → 126.3402 | 99.929 → 2781.343 | +96.41% | 532.24 / 549.92 / 640.52 |

r1 的 2 个跨处理配对降幅相差 0.10 个百分点，中位数 +96.46%。

r1 的 50 个相同步号里，B 的 Host 单步墙时双序均缩短 50 次、均增加 0 次、方向不同或相等 0 次。

各腿测量窗口为 136 个样本、2,994 个 token。逐步 Host 墙时包含当时发生的隐式等待，表中的 p10/p50/p90 来自相同步号的未逐步同步墙时差。[窗口明细](synchronized_windows.csv) · [逐步配对与来源路径](paired_results.json)
